ATLAS

Security

Architecture Explorer | Independent community project

Scope

ATLAS is a fully static, client-side-only application hosted on GitHub Pages. It contains no server-side code, no database, no authentication, no user accounts, and no external API connections. The attack surface is limited to the static files served from this site.

Reporting a vulnerability

If you discover a security issue in ATLAS — for example a cross-site scripting vulnerability in the HTML or JavaScript — you can report it in one of two ways:

  • Confidential reports: Send an email to adem20201111@gmail.com. Use this for reports that you prefer not to disclose publicly.
  • General issues: Open a GitHub Issue for non-sensitive bugs or suggestions.

Context: ATLAS handles no personal data, no authentication credentials, and no server infrastructure. There are no user accounts, secrets, or databases that could be compromised. The practical impact of most issues is limited to the static files served from this site.

Dependency security

ATLAS vendors its only JavaScript dependency — Cytoscape.js 3.29.2 — locally. No scripts are loaded from a CDN. This eliminates supply-chain risk from external script delivery.

Content security

The architecture data in ATLAS is derived from publicly available upstream sources (SAP Architecture Center, Apache-2.0). No user-generated content is accepted or rendered.
