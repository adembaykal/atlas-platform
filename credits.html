ATLAS modifications to source material

ATLAS transforms upstream architecture metadata into JSON indexes, extracts component and hotspot information, and renders architecture preview images from upstream draw.io materials. Some architecture descriptions have been editorially rewritten or expanded from upstream descriptions to support discovery. Those edits are not official SAP statements. For authoritative details, follow the links to the corresponding original architecture documents.

Derived files include atlas-reference-architectures.json, the JSON files in data/, and the PNGs in previews/. See the NOTICE for related attribution and modification information.
