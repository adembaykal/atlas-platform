# Security Policy

## Scope

ATLAS is a fully static, client-side-only application hosted on GitHub Pages. It contains no server-side code, no database, no authentication, and no external API connections.

## Reporting a vulnerability

If you discover a security issue in ATLAS (for example, a cross-site scripting vulnerability in the HTML or JavaScript):

- **Confidential reports:** Email [adem20201111@gmail.com](mailto:adem20201111@gmail.com)
- **General issues:** Open a [GitHub Issue](https://github.com/adembaykal/atlas-platform/issues)

## Dependency security

ATLAS vendors its only JavaScript dependency — Cytoscape.js 3.29.2 — locally. No scripts are loaded from a CDN.

## Supported versions

Only the latest published version at `https://adembaykal.github.io/atlas-platform/` is maintained.
