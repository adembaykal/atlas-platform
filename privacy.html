ATLAS

Privacy

Architecture Explorer | Independent community project

No personal data collected

ATLAS does not collect, store, or transmit any personal data. There are no user accounts, no forms, no analytics scripts, no advertising networks, and no third-party tracking of any kind.

No cookies

ATLAS does not set or read any cookies.

Browser storage

ATLAS stores two small items in your browser to improve the local user experience:

  • localStorage key atlas-component-hint-seen — records that you dismissed the X-Ray feature hint. Value: "1". Persists until you clear your browser storage.
  • sessionStorage key atlas-enter-seen — suppresses the intro animation pulse after first load. Value: "1". Cleared automatically when you close the browser tab.

Both items contain no personal information and are never transmitted anywhere. You can clear them at any time through your browser's site data settings.

External links

ATLAS links to external sites, including the ATLAS GitHub repository, the SAP Architecture Center, and the SAP/architecture-center GitHub repository. These sites have their own privacy practices, which ATLAS has no control over.

Hosting

ATLAS is hosted on GitHub Pages. GitHub may collect standard server access logs (IP address, user agent, referrer, timestamp) as part of serving the site. See GitHub's Privacy Statement for details.

No server-side processing

ATLAS is a fully static site. All computation runs in your browser. No data is sent to any server operated by this project.
